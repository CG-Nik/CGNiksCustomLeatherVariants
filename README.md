# CGNiksCustomLeatherVariants
This mod adds several leather types, some of which can be found as loot, and some of which can be found from Wyrms.  
This mod needs to be on both the Client and Server.  
Requires https://github.com/Circl-NoE/ATTMateriaLib (must be on Server and Client) and https://github.com/CG-Nik/DifferentWyrmMaterials (only needs to be on Server).  

This is an unofficial, fan-made mod for A Township Tale. This mod is not affiliated with or endorsed by the owners or developers of A Township Tale.
